# 众需生活公开演示

这是众需生活的公开体验版，仅用于产品展示和交互测试。

## 页面

- `index.html`：公开演示入口。
- `众需生活-可交互演示.html`：客户端、服务商、主办方和后台流程演示。
- `众需生活-手机下载测试.html`：手机访问、添加到主屏幕和安装说明。

## 发布到 GitHub Pages

1. 在 GitHub Desktop 中选择“添加现有仓库”。
2. 选择本目录。
3. 点击“发布仓库”。
4. 仓库必须是公开仓库，免费 GitHub Pages 才能正常访问。
5. 打开仓库的 `Settings → Pages`。
6. 选择 `Deploy from a branch`。
7. 分支选择 `main`，目录选择 `/ (root)`，保存。
8. 等待部署完成，访问 `https://用户名.github.io/仓库名/`。
